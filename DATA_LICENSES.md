# Data licenses

GeoPulse code is Apache-2.0 (see `LICENSE`). That license does **not** cover the data it reads.
The repository ships no imagery: benchmark manifests and examples reference public data by AOI, time window
and STAC item ID, and `geopulse` fetches it at run time.

| Source | STAC collection (Planetary Computer) | License (from the collection metadata) | Redistribute derived tiles? |
|---|---|---|---|
| Sentinel-1 RTC (gamma0, terrain-corrected) | `sentinel-1-rtc` | CC-BY-4.0 — Catalyst, Microsoft | Yes, with attribution |
| Sentinel-2 L2A surface reflectance | `sentinel-2-l2a` | Copernicus Sentinel data terms (free, full and open) | Yes, with the Copernicus notice |
| Copernicus DEM GLO-30 | `cop-dem-glo-30` | Copernicus DEM license (ESA mission-specific annex) | Check the annex before redistributing |

Required notices when publishing outputs or benchmark tiles:

- "Contains modified Copernicus Sentinel data [year of acquisition]."
- "Sentinel-1 RTC data © Catalyst / Microsoft, CC BY 4.0."
- "Produced using Copernicus WorldDEM-30 © DLR e.V. 2010–2014 and © Airbus Defence and Space GmbH 2014–2018,
  provided under COPERNICUS by the European Union and ESA; all rights reserved."

## Labels

| Benchmark | Label source | License | Fetched from |
|---|---|---|---|
| flood | **Weak labels** generated by GeoPulse (`baseline.weak_labels`: pixels where S1 and S2 agree confidently) | Inherit the imagery licenses above | computed |
| wildfire | **MTBS** burn-severity mosaics (USGS EROS / USDA Forest Service), CONUS 1984–2018 | U.S. Government work, public domain; cite MTBS | Planetary Computer `mtbs` |
| vegetation | **Hansen et al. Global Forest Change v1.12** (`lossyear`, `treecover2000`), 2000–2024 | CC BY 4.0 | `storage.googleapis.com/earthenginepartners-hansen` |

Citations: MTBS Project (USDA Forest Service / U.S. Geological Survey), mtbs.gov; Hansen, M. C. et al. (2013)
High-resolution global maps of 21st-century forest cover change. *Science* 342, 850–853 (v1.12 data update).

All benchmarks also carry a task-agnostic "change" label computed from S1+S2 consensus. Hand-labelled rasters can be
plugged in per event with `label: path.tif` (or `{source: raster, path: ...}`); record their license here first.

## Web map basemaps

The local web UI loads Esri World Imagery and World Dark Gray Canvas tiles for display only. They are not part of
any GeoPulse output. Follow Esri's attribution requirements (shown on the map) and terms of use.
